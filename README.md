# AI-Based Sentiment Analyzer

## Overview
This project analyzes text reviews and predicts whether the sentiment is Positive, Negative, or Neutral using Hugging Face Transformers.

## Features
- Analyze product reviews
- Sentiment prediction
- Confidence score
- CSV upload
- Sentiment visualization

## Technologies
- Python
- Flask
- Hugging Face Transformers
- Pandas
- Matplotlib

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```
